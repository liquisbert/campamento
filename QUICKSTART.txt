## ⚙️ Técnico (Para Developers)

### Nueva Función en Firebase:
```javascript
registerUserWithQR(nombre, qrId, teléfono, rol)
// Registra participante con QR escaneado
// Auto-genera email y contraseña
// Valida QR único
// Envía WhatsApp
```

### Componente Modificado:
```javascript
<ParticipantRegistration onClose={fn} />
// Ahora con 3 pasos y escáner QR integrado
// Llama a registerUserWithQR en lugar de registerUser
```

### Componente Deshabilitado:
```javascript
<Register />
// Ya no permite auto-registro
// Redirige a /login
```
